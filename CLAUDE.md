# Агент лидов — инструкция для Claude на компьютере агента лидов

Эта папка — сборка **агента лидов** агентства PromoEcom: скилл `lidy-fb` ищет в Facebook посты западных Amazon-селлеров,
которые ищут агентство или PPC-специалиста, и шлёт их на Пульт — https://pult-agenta.pult-agenta.workers.dev, пространство
«Лиды» (переключатель в шапке меню). Это **отдельный агент на отдельном компьютере**: скиллы агента маркетплейсов
(отзывы WB/Ozon, реклама) сюда не ставятся, его токен и папки не используются.

Тебя открыли в этой папке, чтобы **установить или обновить агента лидов**. Говори по-русски, коротко. Что можешь — делай
сам; что может только человек — дай короткий список и дождись «готово».

Если тебя запустили по расписанию (`/lidy-fb`) — этот файл не про тебя: выполняй скилл.
Если рядом есть `.git` — это репозиторий разработчика: ничего не устанавливай, как устроено — `README.md`.

## Нельзя
- Вводить пароли и коды, проходить капчу, принимать соглашения, менять настройки аккаунтов Facebook и LinkedIn.
- Менять системные настройки Windows и разрешения Claude — подсказывай человеку, где.

## Установка или обновление
1. Идёт ли прогон: `%USERPROFILE%\.claude\skills\lidy-fb\sostoyanie\.lock` моложе 3 часов — спроси, подождать ли.
2. Запусти сам: `powershell -NoProfile -ExecutionPolicy Bypass -File "<эта папка>\install.ps1"`.
   Нужны строки «OK  скилл lidy-fb», «OK  config.json» (или уже был), «OK  отправщик в автозагрузке», «OK  отправщик на связи с Пультом».
   «нет config.json» — файл с адресом Пульта и токеном агента лидов выдаёт разработчик; его кладут рядом с `install.ps1`.
3. Chrome: загрузи инструменты Claude in Chrome, `list_connected_browsers` — нужен браузер с `onThisComputer: true`.
   Открой facebook.com во вкладке своей группы: должна быть лента, а не страница входа. Вход — только человек.
4. Расписание: одна задача «Лиды Facebook» — каждый день в 10:30 и 18:30 — команда `/lidy-fb`. Создаёшь после «да» человека;
   инструмента нет — дай фразу: «Создай задачу по расписанию «Лиды Facebook»: каждый день в 10:30 и 18:30 запускать /lidy-fb».
5. Что делает только человек:
   - Входит в Facebook (тестовый аккаунт агентства) в этом Chrome; в Claude in Chrome для facebook.com — «Всегда разрешать».
   - Режим разрешений Claude для задач по расписанию — без подтверждений.
   - Windows не засыпает и не блокируется; окно Chrome не сворачивать; в Chrome выключить «Экономию памяти».
   - В этом Chrome людям Facebook не листать в часы прогонов.
6. Пробный прогон при человеке: `/lidy-fb`. На Пульте → «Лиды» → «Агент лидов» появится прогон, в «Лидах» — найденное.

## Если что-то не так
- **Пауза:** файл `ПАУЗА.txt` в `%USERPROFILE%\.claude\skills\lidy-fb\` (агент ставит его сам при капче или выходе из
  аккаунта — человек входит / проходит проверку и удаляет файл). Пауза с Пульта — кнопка в «Агент лидов».
- **Лиды не доходят:** файлы копятся в `…\lidy-fb\outbox\`, журнал — `…\lidy-fb\sostoyanie\otpravka.log`.
- **«сборщик не видит постов»** на Пульте — Facebook поменял вёрстку, нужен разработчик (`sbor.js`).
